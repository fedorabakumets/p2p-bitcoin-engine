# P2P Bitcoin Engine

Обменник BTC за рубли через обычного Telegram-бота. Mini App в первую версию не входит.

Кнопки только показывают состояние из PostgreSQL. Если бот или Telegram недоступны, заявки, escrow и ledger остаются в базе.

## Как устроены деньги

В ledger только биток, в сатоши. Рубли на платформу не приходят: клиент переводит всю сумму на СБП трейдера. Наценка в рублях остаётся на карте трейдера и в ledger не проводится.

Клиент получает биток на сумму «получите». С депозита трейдера списывается больше. Разница — комиссия платформы, из неё же берётся партнёрское начисление. Партнёрский баланс тоже в битках. Рубли в меню партнёра — только пересчёт для показа.

Скриншот можно приложить к спору. Сам по себе он оплату не подтверждает.

Снимок котировки копируется в заявку. Поздний курс старую заявку не пересчитывает.

- `client_btc_sats` — сколько уйдёт клиенту
- `platform_fee_sats` — сколько останется платформе
- `referral_sats` — часть комиссии платформы, не добавка сверху
- `trader_lock_sats` = `client_btc_sats` + `platform_fee_sats`

Рубли хранятся целыми копейками.

## Процесс

Бот на aiogram 3 вызывает сервисный слой напрямую. FastAPI в том же процессе нужен для админки и будущих вебхуков процессора. Захват заявки трейдером — одна транзакция PostgreSQL, не блокировка в Redis. Redis нужен для таймеров и лимита запросов.

Первый запускаемый контур: клиент, заявка, котировка, пул трейдеров, escrow, ledger, биток, рефералка, админка. Процессор, умный роутинг и несколько монет — отдельные релизы. У заявки уже есть `execution_channel`, чтобы позже подставить процессор.
